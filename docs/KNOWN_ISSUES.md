# Known issues and reproduction gaps

1. **PRO-seq negative strand:** `archive/pro/spt6/pauseindex_proseq.py` sets negative-strand body start to TSS−250 and body end to TES+250. For ordinary long genes this reverses the interval and assigns body signal zero. The manuscript specifies the interval from TES to TSS−250. This source also does not enforce separate strand tracks or exclude genes with no signal in every sample. Retained unchanged for provenance; do not use it to substantiate manuscript pausing results without repair and validation.
2. **MNase grouping:** `mnase_stable.ipynb` plots four positional-difference quantiles, but its final BED export uses `pd.qcut(..., 2)`. These BED exports do not implement the manuscript's lowest/highest quartile definition. Quartiles describe cross-control positional agreement, not a direct estimate of temporal nucleosome stability. The cleaned notebook only removes outputs; it does not repair scientific logic.
3. **ChIP processing:** `chipseq_se.sh` and `spikein.sh` are legacy single-end examples; the manuscript describes paired-end ChIP-Rx. They rename/move reads and remove intermediate files. The spike-in helper aligns to dm6 but is not the complete MAPQ-filtered scaling workflow described in the manuscript. Do not execute on the sole copy of input data.
4. **DESeq2:** archived R scripts have local sample-order assumptions, human–mouse orthology filters and module-specific fold-change cutoffs. Do not assume the manuscript's general absolute log2FC >0.58 cutoff, figure-specific >1 cutoff, or apeglm shrinkage is implemented everywhere. Confirm sample names against count columns rather than relying on positional renaming.
5. **GSEA:** archived scripts may rank using fold changes, adjusted P values, or a composite metric; the manuscript specifies sign(log2FC) × −log10(raw P) for expression analyses and a separate H2A.Z/RNA composite ranking. Confirm each module's exact ranking, gene universe, species, GMT version, duplicate policy, permutation count and random seed. Gene-set downloads are not frozen.
6. **Composite score:** `plot_score_relationships.py` explicitly computes z(H2A.Z) + mean(MED12OE log2FC, SPT6OE log2FC), maps RefSeq using mm39 and averages transcript signals per gene. Its H2A.Z input is named `mousetss500_h2az.txt`; this alone does not establish MNase-defined +1-nucleosome quantification. The z-score is computed before joining RNA results. Confirm the intended universe and interval with final analysis records.
7. **Statistics:** H2A.Z tertile plotting helpers use pairwise Mann–Whitney tests without multiplicity adjustment. Paired condition comparisons in the manuscript require paired tests where stated. These plotting helpers are not interchangeable with those comparisons.
8. **Paths and dependencies:** Windows, WSL, macOS and home-directory paths remain in source archives, including local package-runtime injection and Arial font paths. Inputs, package versions and helper imports must be restored before execution.
9. **Missing stages:** a confirmed first-downstream-MNase-peak caller, complete TT/PRO matched-bin ratio calculation, full raw-read PRO/TT pipeline, final Fig. 4 factor heatmap generation and GEPIA survival exports were not located in the selected scripts. The `bw_plot_11.sh` helper is visualization only and contains a malformed TES command; it does not calculate an elongation ratio.
10. **Provenance:** code similarity is not proof of final figure provenance. No archived script has been certified to regenerate a numbered panel. Experimental blots, histology and mouse measurements are outside this code collection.
